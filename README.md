# ExpenseTracker-Compose

A personal Android portfolio project for tracking income and expenses with Compose, MVVM, Room, and reactive state.

## Current starter features
- Jetpack Compose + Material 3 UI
- MVVM with StateFlow
- Room transaction storage
- Hilt dependency injection
- Income/expense summary
- Unit-test starter

## Tech stack
Kotlin · Jetpack Compose · Material 3 · MVVM · StateFlow · Hilt · Room dependencies · Coroutines · JUnit

## Open in Android Studio
1. Extract this repository folder.
2. Open the folder in Android Studio.
3. Use JDK 17 and allow Gradle sync to finish.
4. Run the `app` configuration on an emulator or Android device.
